# The store's text

The text every example in this book learns from: the product names, classes and descriptions of WANDS, the Wayfair
ANnotation DataSet, a public product-search dataset. Generated by `prep/wands_text.py`; never edit these files by hand.

**Source:** https://github.com/wayfair/WANDS, commit `3b74dcf4ba29ab8ff3e6a50b5b09fc627cb882b5`.
**Licence:** MIT, Copyright (c) 2021 ecir2022. See [`LICENSE`](LICENSE), copied from the source repository.
**Paper:** Chen, Y., Liu, S., Liu, Z., Sun, W., Baltrunas, L. and Schroeder, B. (2022). WANDS: Dataset for
Product Search Relevance Assessment. ECIR 2022.

| File | Rows | What |
| --- | --- | --- |
| `products.csv.gz` | 42,815 | `product_id`, `split`, `name`, `product_class`, `description` |

Splits (seed 2026): 34,252 train, 4,282 validation and 4,281 test
products; each product is in one. About 2,826,279 words of names and descriptions in all.

**Prepared:** WANDS's text is already lowercased, with spaces around punctuation. 179 products whose name or
description names the store or its own brands are left out, so no model in the book learns to write the store's name.
Descriptions are cut at the last sentence end within 600 characters, or at a word boundary when there is
none.
